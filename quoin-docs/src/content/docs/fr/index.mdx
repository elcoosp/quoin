Quoin est une couche d'abstraction réactive agnostique vis-à-vis du framework pour Rust. Vous écrivez votre logique métier une fois contre un petit ensemble de traits — signaux, effets, tâches asynchrones, annulation, état global — et le même code tourne sous GPUI, Leptos, Dioxus, Xilem ou Floem. Vous activez exactement une fonctionnalité de framework à la compilation, et la [suite de conformité](/explanation/backend-parity/) partagée garantit que chaque adaptateur se comporte identiquement.

## Frameworks supportés

| Framework | Crate d'adaptateur | Statut |
| --- | --- | --- |
| [GPUI](https://github.com/zed-industries/zed) | `quoin-gpui` | Support complet |
| [Leptos](https://leptos.dev/) | `quoin-leptos` | Support complet |
| [Dioxus](https://dioxuslabs.com/) | `quoin-dioxus` | Support complet |
| [Xilem](https://github.com/linebender/xilem) | `quoin-xilem` | Support complet |
| [Floem](https://github.com/lapce/floem) | `quoin-floem` | Support complet |

Activez exactement une fonctionnalité de framework dans votre `Cargo.toml` — Quoin l'impose par une vérification à la compilation.
