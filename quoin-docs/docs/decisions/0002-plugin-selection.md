# ADR 0002 — Plugin selection for the Starlight docs

- **Status:** Accepted
- **Date:** 2026-11-07
- **Deciders:** Documentation Architect (autonomous run)

## Context

The documentation-architecture brief lists HiDeoo-maintained "bells and whistles" plugins, to be installed when compatible with Starlight 0.42.x / Astro 7.4.x — and omitted, with a recorded reason, when irrelevant. Quoin is a **Rust** workspace (no TypeScript public API, no OpenAPI spec, no blog content), verified by reading the repository.

Verified versions at execution time (2026-11-07): `starlight-links-validator` 0.27.0, `starlight-image-zoom` 0.16.2, `starlight-heading-badges` 0.8.0, `starlight-llms-txt` 0.12.0 — all declare compatibility with `astro >= 7.2.10` / `@astrojs/starlight >= 0.42.0` (heading-badges `>= 0.41.0`).

## Decision

**Installed:**

| Plugin | Purpose |
| --- | --- |
| `starlight-links-validator` | Fails `pnpm build` on broken internal links — release blocker. |
| `starlight-image-zoom` | Click-to-zoom images. |
| `starlight-heading-badges` | Badges rendered in headings and the TOC (used to flag unreleased features). |
| `starlight-llms-txt` | Emits `/llms.txt`, `/llms-small.txt`, `/llms-full.txt` for AI-agent discoverability (satisfies the AI-discoverability requirement via a maintained plugin instead of a hand-rolled build script). |

**Omitted, with reasons:**

| Plugin | Reason |
| --- | --- |
| `starlight-typedoc` | Generates API reference from **TypeScript** projects. Quoin's public API is Rust; its rendered API reference belongs to rustdoc, not TypeDoc. Inventing a TS surface for it would document something that does not exist. |
| `starlight-openapi` | No OpenAPI spec exists in the repository; the project ships no HTTP API. |
| `starlight-blog` | There is no blog content to publish. The repository's `CHANGELOG.md` is generated by git-cliff from Conventional Commits and lives with the source; mirroring it as blog posts would duplicate a generated artifact and invite drift. |
| `starlight-versions` | The skill flags it as early-development software, and Quoin itself is a single-version 0.1.0 workspace with no released versions to document. Versioned docs have nothing to version yet. |

## Consequences

- Search remains Starlight's built-in **Pagefind** (kept, zero-config, per the brief). No approved Algolia DocSearch application exists for Quoin, so DocSearch is not added.
- If a TypeScript surface or OpenAPI spec ever appears, revisit this ADR.
